## 📖 项目简介

Claude Code 是 Anthropic 官方推出的智能编程(agentic coding)工具,常驻你的终端,理解你的整个代码库。用自然语言下指令,它就能执行例行任务、解释复杂代码、处理 git 工作流,让你写代码更快更省心。它可以在终端、IDE 中使用,也可以直接在 GitHub 上 @claude 进行协作。本仓库是其官方 README 的中文翻译版本,附中文安装与上手教程。

## ✨ 主要特性

- 🖥️ **终端即战场**:智能编程工具原生运行在终端中,无需离开命令行。
- 🧠 **理解整个代码库**:不用手工挑上下文,它能自行检索、理解项目结构与依赖。
- 💬 **自然语言驱动**:一句中文/英文指令即可完成例行任务、解释复杂代码、修改与重构。
- 🔀 **原生 git 工作流**:提交、分支管理、历史查询、解决冲突一气呵成。
- 🏢 **多环境可用**:终端、IDE 里都能用,还可以在 GitHub 上 @claude 处理 issue 和 PR。
- 🧩 **插件系统**:仓库内置多个官方插件,通过自定义命令与 agents 扩展功能。
- 🐞 **一键反馈**:内置 `/bug` 命令,在工具内直接报告问题。
- 📦 **安装方式丰富**:官方安装脚本、Homebrew、WinGet 全平台覆盖(Node.js 18+ 环境友好)。

## 🚀 快速开始

**1. 安装 Claude Code(macOS / Linux 推荐官方脚本):**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**2. Windows PowerShell 推荐命令:**

```powershell
irm https://claude.ai/install.ps1 | iex
```

**3. 也可以用包管理器:**

```bash
brew install --cask claude-code
```

```powershell
winget install Anthropic.ClaudeCode
```

**4. 进入项目目录并启动:**

```bash
cd 你的项目目录
claude
```

> ⚠️ 官方说明:通过 npm 安装的方式已弃用,请优先使用上述推荐方式。
